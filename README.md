# GlutiliNO weboldal

Statikus, reszponzív GlutiliNO weboldal, közvetlen Vercel-telepítéshez.

## Vercel

1. Importáld ezt a GitHub-repót a Vercelben.
2. Framework Preset: **Other**
3. Build Command: hagyd üresen.
4. Output Directory: hagyd üresen.
5. Deploy.

A webhely belépési pontja a gyökérben található `index.html`.
